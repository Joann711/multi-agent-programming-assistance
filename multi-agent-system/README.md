# Multi-Agent Programming Assistant

A multi-agent system designed to assist with Python programming through code review, debugging, code correction, and validation.

The project explores the use of specialized AI agents to handle different stages of the programming assistance process, rather than relying on a single model to perform all tasks.

## Overview

The system uses four specialized agents, each responsible for a different stage of code correction. The agents communicate by passing their findings and feedback to one another, working together to produce corrected Python code.

The system is implemented in Python and uses **Ollama** to run **Qwen2.5-Coder 7B** locally.

## System Architecture

The system consists of four agents:

| Agent | Responsibility |
|---|---|
| **Reviewer** | Analyzes the original code to identify syntax errors, logical errors, and potential coding issues. |
| **Debugger** | Investigates identified errors, explains their possible causes, and suggests corrections. |
| **Fixer** | Generates corrected code based on the Reviewer and Debugger feedback. |
| **Tester** | Reviews the corrected code and identifies any remaining issues. |

### Workflow

1. The user provides Python code and its intended functionality or problem description.
2. The Reviewer analyzes the code and identifies potential errors.
3. The Debugger investigates the identified issues and provides suggestions.
4. The Fixer generates a corrected version of the code.
5. The Tester reviews the corrected code and provides feedback.
6. If issues remain, the Fixer receives one additional opportunity to revise the code.
7. The system returns the final corrected code and the number of identified errors.

## Technologies Used

- **Python** – Main programming language.
- **Ollama** – Local execution of language models.
- **Qwen2.5-Coder 7B** – Language model used by the agents.

## Setup

### 1. Install Ollama

Download and install Ollama:

https://ollama.com/

### 2. Download the language model

Run the following command:

```bash
ollama pull qwen2.5-coder:7b
```

### 3. Start Ollama

Ensure that the Ollama service is running locally.

The system communicates with the Ollama API through:

```text
http://localhost:11434/api/generate
```

### 4. Install Python dependencies

Install the required packages:

```bash
pip install requests pandas numpy
```

Additional dependencies may be required depending on the notebook implementation.

### 5. Run the system

1. Open the project notebook using Jupyter Notebook or JupyterLab.
2. Ensure Ollama is running and the required model is available.
3. Execute the notebook cells in order.
4. Provide the Python code and its description to the system.

## Output

The system produces:

- **Corrected Code:** The final code generated by the multi-agent system.
- **Number of Errors:** The number of errors identified during the initial review.
