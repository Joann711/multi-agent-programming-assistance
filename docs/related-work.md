1 - AdaCoder: An Adaptive Planning and Multi-Agent Framework for Function-Level Code Generation \
  Main Idea: This paper proposes AdaCoder, which is an adaptive multi- agent specialized in function-level code generation by adjusting the use of agents based on whether the generated code contains errors. \
  Methodology: Their framework consist of four main agents: a prompt engineer for generating plans, a programming
assistant for code generation, a code evaluator for testing, and a debug specialist to fix errors based on the plans. With two phases, the first includes the code generation and testing, then the second phase to plan and fix the errors in the generated code. \
  Findings: Results showed improvement in code generation compared with the baseline, MapCoder, with 27.69% higher pass@1 value, faster execution, and lower token consumption. However, the paper focused only on function level programming, and it does not establish how well the approach generalizes to more complex programming tasks and environments. \
2 - From Tool to Partner: Exploring the Roles of Embodiment on AI Agent in Pair Programming. \
  Main Idea: An AI agent as a programming partner in Virtual Reality VR pair programming environment. It focused on how the use of AI agent affects programming learning and the user experience. \
  Methodology: Programming environment depended on VR, and focused on block-based programming language. The study compared a voice-only AI agent with an embodied AI agent that used GPT-4o, and it had two type of responses, reactive response when the user asks a question, and a proactive response that is triggered during tasks depending on the user states. \
  Findings: The paper focused on evaluating effectiveness of AI agent in supporting programming education. They measured the average knowledge assessment, which showed an increase from 50% to 88.9% after using embodied AI agent, with a similar increase using voice-only AI agent. Limitations were about the limited number of programming tasks and actions for the agents. \
