1 - AdaCoder: An Adaptive Planning and Multi-Agent Framework for Function-Level Code Generation \
  Main Idea: This paper discusses the current framework in code generation using LLMs, by comparing multi-agents that uses ChatGPT with other open-source LLMs. It also proposes a framework called AdaCoder, which is an adaptive multi-agent specialized in function-level code generation by adjusting the use of agents based on whether the generated code contains errors. \
  Methodology: Their framework consist of four main agents: a prompt engineer for generating plans to fix errors, a programming assistant for code generation, a code evaluator for testing, and a debug specialist to fix errors based on the plans.
