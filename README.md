# A Multi-Agent System for Programming Assistance

A research and implementation project exploring a multi-agent system for programming assistance through **code review, debugging, testing, and error correction**. Done for my Advanced AI course, which I’m currently taking as part of my Master’s degree.

## Overview

This project investigates whether using multiple specialized agents can improve programming assistance by assigning different software-development tasks to separate agents.

The system is designed around four main roles:

* **Code Review Agent** — analyzes code and identifies potential errors or issues.
* **Testing Agent** — evaluates the code using test cases and reports test results.
* **Debugging Agent** — analyzes errors and investigates their possible causes.
* **Error Correction Agent** — uses the available feedback to suggest corrections to the code.

The project will evaluate the system experimentally using programming problems and predefined evaluation metrics.

## Research Goal

The main goal is to investigate the effectiveness of a multi-agent approach to programming assistance and compare its results with a baseline approach.
